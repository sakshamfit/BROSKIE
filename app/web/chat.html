Chat questions, answered

Is Plus One chat free?

Yes. Plus One is completely free on web, Android and iOS — create a username and password and start chatting. No ads, no in-app purchases.

How do disappearing messages work?

Set a timer for a whole chat or a single message: 30 seconds, 5 minutes, 1 hour, or 24 hours. When it expires, the message is hard-deleted from the server and vanishes from every device.

Can I chat in groups?

Yes. Groups support replies, reactions, edits, forwards, voice notes, images, live polls, and admin controls — rename, promote, remove. The last admin never vanishes.

What platforms does it run on?

The web app is an installable PWA at plusoneco.in/app; Android runs via APK or Expo Go; iOS runs via Expo Go. Everything syncs in real time under one One ID.
