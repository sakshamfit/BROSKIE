Community type · House Party

Find a house party crew on +one

The House Party category is for the other half of a night out: someone hosting and everyone else figuring out if they should be there. The community is the event page, the guest list and the group chat at once — coords, timing, playlist and “who's bringing the speakers” in one place that survives after the party and is ready for the next one.

Polls run the decisions — theme yes or no, rooftop vs flat 402, DJ Arpit versus shared playlist — and the answers are visible before anyone commits. Photos and voice notes from the night land in the same chat, which is exactly what the next host needs: the spot, the vibe, the people who show up.

This is also where join policies earn their keep: most hosts run invite-only and share a +one/c/… code with the people they want, with the door closing when they rotate the code after the party. Ask-to-join groups work as open-but-vetted — apply, get approved, see the next plan on the wall.

What a house party looks like inside +one

  • You host and want one group for guests, RSVPs and the aftermath photos
  • You're the guest who wants to know what the vibe is before Saturday
  • You're throwing something with a co-host and the two of you need working admin powers

Built with the group tools that ship in the app

  • Invite links with rotating codes — the guest list is exactly that
  • Ask-to-join for open-but-not-for-everyone parties
  • Multiple admins run the plan; the last admin can't be removed
  • Media, voice notes and afterparty calls in the same group chat
