Community type · Running Group

Find a running group on +one

Running communities on +one are small public groups built around an actual weekly plan: the 6 am loop, the Sunday long run, the before-work 5k that doesn't get cancelled because someone's alarm didn't. They live in The Network's Communities section under the Running Group category, with member counts on each card so you can tell a living crew from an abandoned one.

Where the run starts gets decided the way everything on +one does — with a live poll. “Sunday long run — where?” with Lodhi Garden 6 am against Dew DEGREES 6:30, the bars filling as the group votes. Pace talk, route pins and the post-run photo land in the same group chat, so a newcomer who joined on Tuesday already knows the Friday plan.

Most crews are open — anyone can walk in off the Discover grid and show up Sunday. Others run ask-to-join so the organiser approves first, or hand out invite links for the regulars. Either way, the accountability is the point: the group sees who voted, who confirmed, who's coming.

What a running group looks like inside +one

  • You tried a fitness app and realised the hard part isn't the plan — it's not running alone
  • You're training for a 5k/half/marathon and want pace partners and weekly long-run dates
  • You run early and want five people who will still be there when it's raining

Built with the group tools that ship in the app

  • Polls settle the route, start time and distance in minutes, not days
  • Voice notes and shared photos from the run itself in the group chat
  • Group calls when someone's running the long loop on their own
  • Disappearing ink per message — the logistics chatter cleans itself up
