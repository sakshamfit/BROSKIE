Purpose-based groups

Find your people by what you do

Communities on Plus One are interest-based groups inside The Network — running groups, study groups, club nights, chai chats, trip planning, game nights. Pick a category, set how people join, and start talking in real time.

You decide how people join

  • Open — anyone can join instantly
  • Ask to join — an admin approves each request
  • Invite only — admins add people directly

Groups that actually work

  • Live polls with bars that fill as votes land
  • Admins rename, promote and remove — the last admin never vanishes
  • Disappearing ink per chat or per message
  • Shared media, voice notes and calls with every member
  • Discover grid with category filters and live member counts
